# basic_offline_first_app

A reference Flutter application that demonstrates how to build an
**Offline-First** app using the `local_remote_synchronization` ecosystem.

> 🗓 **In development.** This example will be expanded alongside the Core package.

## Purpose

- Show how to wire up a `LocalStorageAdapter` and a `RemoteSyncAdapter`.
- Demonstrate reading from local storage only in the UI layer.
- Illustrate immediate local writes followed by background sync.
- Show conflict resolution strategies in a real Flutter widget tree.

## Status

This is a scaffold. The example app will be fleshed out once the Core
contracts and at least one local and one remote adapter are implemented.
